EXPLORE AFRICA — INSTALLABLE WEB APP

This package is a Progressive Web App (PWA), built from the supplied Explore Africa wildlife website. It is not a standalone APK.

PUBLISHING
1. Extract this ZIP.
2. Upload all files and folders inside it to the root of a GitHub repository (keep index.html, manifest.webmanifest, service-worker.js, and icons folder together).
3. Enable GitHub Pages for the repository (Settings > Pages > Deploy from a branch > main > /(root)).
4. Open the published HTTPS website in Chrome on Android.
5. Tap the Install Explore Africa button if it appears, or Chrome menu ⋮ > Install app / Add to Home screen.

NOTES
- HTTPS hosting is required for service workers/PWA installability; GitHub Pages provides HTTPS.
- Open the published website once while online so its app shell can be cached for offline launch.
- Product/seller content and enquiry features remain the same as the supplied prototype; this package does not add a live database, payment processing, seller accounts, or an APK.
